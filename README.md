# Lab 01: First Streamlit App

## Project Theme

EduRisk Analytics

## Description

This is my first Streamlit web app built using Streamlit and Pandas for student risk prediction and monitoring.

## Features

- Sidebar navigation (Home, Student Data, About)
- Student data table
- Dashboard metrics (Total Students, Average Score, Average Attendance, Low Score Students)

## Tools Used

- Python
- Streamlit
- Pandas
- VS Code

## How to Run

```bash
streamlit run app.py
```
